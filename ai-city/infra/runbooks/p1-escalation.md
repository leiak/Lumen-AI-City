# P1 告警值班手册（§41.9）

> **响应时间**：30 分钟内有人响应，2 小时内处理完。

## 常见 P1 场景

### 1. MemoryService 慢查询
**症状**：memory_recall_duration_ms P99 > 200ms

**排查**：
1. 看 Redis 连接数（连接耗尽会导致排队）
2. 看 Milvus 索引（IVF 参数需要重新调）
3. 看 PG 慢查询日志

**处置**：
- 短期：增加 Redis 副本
- 中期：调整 Milvus IVF 参数
- 长期：缓存热门 query

### 2. Federation 错误率高
**症状**：federation_errors_total > 5%

**排查**：
1. 看具体哪个外部 Agent 报错
2. 检查 ed25519 / mTLS 证书
3. 检查网络（跨城专线？）

**处置**：
- 临时下线问题 Agent
- 通知对方维护方
- 走补偿 Saga 撤销未完成交易

### 3. 客户端预测 P99 偏差大
**症状**：客户端报告的 position 与服务端校正 > 1m 频繁

**排查**：
1. 看网络 RTT（高 RTT → 预测窗口要小）
2. 看玩家移动频率（高频移动需要更短 tick）
3. 看服务端协调 RPC 延迟

**处置**：
- 调整预测阈值
- 优化服务端 RPC
