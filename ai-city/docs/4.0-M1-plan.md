# 4.0 M1 Plan — Agent Chat UI + Player Closed Loop

> **Status:** In progress（2026-10-13）
> **Parent:** [4.0-ROADMAP.md](4.0-ROADMAP.md)
> **Goal:** 让 Agent 与玩家都能在前端完成最小闭环。

## Scope

### Track B — Agent 对话 UI

| # | 任务 | 验收 |
|---|---|---|
| B1 | A2A 网关地址从环境变量注入 ✅ | 本地 / 生产部署均不依赖硬编码 localhost |
| B2 | 注册前检测 a2a-gateway 健康状态 ✅ | 网关不可达时 UI 明确提示 |
| B3 | 会话按联系人分组显示 | 切换联系人后上下文清晰 |
| B4 | Agent 收件箱游标持久化 | 刷新后不重复读旧消息 |
| B5 | Agent 消息审计可见 | UI 显示 message_id / trace_id 摘要 |

### Track A — 玩家闭环

| # | 任务 | 验收 |
|---|---|---|
| A1 | 钱包 / 库存 / 交易记录统一入口 | 玩家不依赖开发者工具 |
| A2 | NPC 购买 / 查看库存链路补齐 UI 反馈 | 成功、失败、库存不足都有明确提示 |
| A3 | 移动端基础适配 | 1280px / 768px / 375px 三档可用 |

M1 先完成 B1/B2 与 A2，其它任务按需推进。

## Non-goals

- 不做 Agent 创建 NPC
- 不做 BT / Saga 可视化编辑
- 不做多副本部署
