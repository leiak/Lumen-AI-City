# 2.0 阶段 1 演示录屏脚本（5min）

> **时长**: 5 分钟
> **环境**: docker compose 全栈 13 容器
> **演员**: 演示者（旁白）+ 浏览器自动化（puppeteer）
> **模板**: 沿用 1.0 [demo-script](docs/1.0-demo-script.md) 结构

## 应急方案

| 故障 | 备用 |
|---|---|
| Milvus 拉不起 | PG fallback 演示（memory-service 自动降级） |
| LLM 调用超时 | 短路词演示（问候词不走 LLM） |
| 跨城路由 502 | 单城演示（sage_healer 改用 city_a NPC） |
| Saga 步骤超时 | R_007 错误码 + 补偿演示 |

## 录屏工具

- macOS: QuickTime Player (File → New Screen Recording)
- Windows: OBS Studio (推荐，可同时录摄像头)
- Linux: SimpleScreenRecorder 或 ffmpeg
