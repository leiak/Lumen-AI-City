# 2.0 阶段 2 — 1min 录屏脚本

> **目标**: 5 NPC 流式对话 + emotion overlay + acceptance_2_1 验收
> **时长**: 1 分钟（vs 2.0 阶段 1 录屏 5min）
> **环境**: docker compose 全栈 13 容器 + LLM (Claude Sonnet 4.6 via LiteLLM)
> **演员**: 演示者（旁白）+ 浏览器 (localhost:3000 WorldMap)
> **依赖**: 2.0 阶段 1 已完成（13 容器健康、acceptance_2_0 5/5 PASS）

## 录制规格

| 项 | 规格 |
|---|---|
| 时长 | 1:00 |
| 分辨率 | 1920×1080 (1080p) |
| 帧率 | 30 fps |
| 格式 | WebM（GitHub README 兼容）/ MP4 |
| 文件大小 | ≤ 3MB |
| 音频 | 可选（讲解词录制） |

## 详细镜头

### Shot 1 (0:00-0:25) — 王老板流式对话

- 进入 WorldMap (localhost:3000 → 自动重定向 /world)
- 点王老板（`npc_wang_boss_001`，坐标 (3,3)）
- 弹出 NPCDialog 浮窗
- 在输入框输入 "点菜"
- **截屏重点**：
  - 王老板句子级出现（"好的，"/"客官想吃点啥？"/"红烧肉、清蒸鱼都有"）
  - 😊 emotion overlay（happy 类）
  - sentence_idx 递增 / end marker `<end>` 触发 done
- 旁白："流式 LLM — 句子级到达，emotion 8 类标签同步推送"

### Shot 2 (0:25-0:50) — 5 NPC 并列流式

切换到其他 4 NPC（每个 6 秒，共 25s）：

| NPC | ID | 触发输入 | Emotion |
|---|---|---|---|
| grace_healer | `npc_grace_healer_001` | "我最近失眠" | 🤔 concerned |
| snack_owner | `npc_snack_owner_001` | "好吃吗？" | 😳 shy |
| book_keeper | `npc_book_keeper_001` | "借本书" | 🤨 skeptical |
| dance_leader | `npc_dance_leader_001` | "跳支舞吧" | 😲 excited |

**截屏重点**：
- 不同 emotion overlay 切换（🤔 → 😳 → 🤨 → 😲）
- sentence_by_sentence 渲染（每 NPC 1 个浮窗）
- emotion tag 解析（`<emotion>happy</emotion>` → 😊 emoji overlay）

**旁白**：每 NPC 流式响应 + emotion overlay 随情境自适应

### Shot 3 (0:50-1:00) — acceptance_2_1 5/5

- 切回终端
- 跑：
  ```bash
  docker compose exec a2a-gateway /app/acceptance_2_1
  ```
- **截屏重点**：

  ```
  [3] sentence-by-sentence .... OK

  ```
- 旁白："自动化验收 — 30s 跑完 5 步 E2E 闭环"

## 应急方案

| 故障 | 备用 |
|---|---|
| LLM 报错（5xx / timeout） | 跳到 Shot 3 验收脚本演示（acceptance_2_1 仍可跑通 mock 路径）|
| web 渲染失败（hydration error） | 录 web 静态截图（playwright screenshot）+ terminal acceptance 拼接 |
| EmotionValidator 抛错 | 降级为 neutral（已实现）— 旁白说明"已自动降级"|
| 流式 buffer 阻塞 | 跳到 acceptance_2_1 演示底层协议 |

## 录制前检查

```bash
# 1. 全栈健康
docker compose ps          # 13 容器 healthy

# 2. LLM 可达（ANTHROPIC_API_KEY 已注入 a2a-gateway）
docker compose exec a2a-gateway env | grep ANTHROPIC_API_KEY

# 3. 5 NPC seed 已加载
docker compose exec postgres psql -U aicity -d aicity -tAc \
  "SELECT id FROM npc WHERE id LIKE 'npc_%' ORDER BY id;"
# 期望 5 行

# 4. acceptance_2_1 二进制存在
docker compose exec a2a-gateway ls -la /app/acceptance_2_1

# 5. 浏览器（localhost:3000）能进入 WorldMap
```

## 录制工具

- macOS: QuickTime Player（File → New Screen Recording）
- Windows: OBS Studio（推荐，可同时录摄像头）

- 浏览器自动化（可选）：Playwright `await page.video.saveAs('demo.webm')`
