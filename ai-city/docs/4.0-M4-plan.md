# 4.0 M4 Plan — Compliance + Multi-Replica + Stability

> **Status:** In progress（2026-10-14）  
> **Parent:** [4.0-ROADMAP.md](4.0-ROADMAP.md)  
> **Goal:** 在 Production Core GA 后补齐用户权利、横向扩容、滚动升级和稳定性证据。

## Scope

### D1 — Privacy / PIPL / GDPR

| # | 任务 | 验收 |
|---|---|---|
| D1.1 | 同意账本 ✅ | 必需处理不可拒绝；analytics / marketing / third-party 可独立撤回 |
| D1.2 | 个人数据导出 ✅ | 导出 profile、钱包、交易、位置、购买记录，并写入导出请求证据 |
| D1.3 | 个人数据匿名化 ✅ | 玩家档案去标识化；财务和监管审计记录按合法理由保留 |
| D1.4 | 合规 API 鉴权与测试 ✅ | 未授权请求 401；无效请求 400 |
| D1.5 | 玩家隐私面板 ✅ | 可在 HUD 查看和撤回授权、导出数据、匿名化账户 |

Contract:

- `GET /v1/privacy/consent`
- `PUT /v1/privacy/consent`
- `GET /v1/privacy/export`
- `POST /v1/privacy/erase`

Migration: `packages/proto/pg-schema-4.0-compliance.sql`

### D2 — Multi-replica and rolling deployment

| # | 任务 | 验收 |
|---|---|---|
| D2.1 | 副本端口解耦 ✅ | API / Web 副本不占用宿主机端口 |
| D2.2 | Nginx edge gateway ✅ | 单一入口代理 API 与 Web |
| D2.3 | 滚动升级脚本 ✅ | API Gateway 2 副本逐个替换，期间 edge health 可用 |
| D2.4 | 回滚命令 ✅ | 上一镜像可重新拉起 2 个健康副本 |

Commands:

```bash
REPLICAS=2 sh scripts/rolling-upgrade.sh api-gateway apply
REPLICAS=2 sh scripts/rolling-upgrade.sh api-gateway rollback <previous-image-id>
```

### D3 — 7-day stability

Runbook: [4.0-M4-ops-runbook.md](4.0-M4-ops-runbook.md)

| # | 任务 | 验收 |
|---|---|---|
| D3.1 | 稳定运行窗口 ✅ 采集中 | 监控容器持续运行，证据按 30 秒写入 `artifacts/stability/`；7 天窗口未结束，任务不可标记完成 |
| D3.2 | 错误预算 | 5xx < 0.1%，p95 < 2s |
| D3.3 | 数据完整性 | migration / backup / Kafka offset 均无回退 |

D3 需要连续时间窗口，不能在本轮单次开发会话中伪造完成。

## Validation 2026-10-14

- M4 D3 baseline：6 项检查、0 失败、p95 约 0.026s。
- `stability-monitor` 已启动并通过 healthcheck，证据文件持续累计。
- `/health` 与 `/metrics` 不再被网关限流误伤。

- `go test ./...`（api-gateway）通过。
- `docker compose config`（base + scale）通过。
- 生产 overlay `config` 通过（显式 ACL / MinIO 占位变量）。
- 合规 live smoke：注册 → consent update → export → erase 全部成功。
- 玩家 HUD 回归：13/13 PlayerHUD tests 通过，隐私授权更新覆盖通过。
- 本机 `rolling-upgrade.sh api-gateway apply`：2 副本逐个替换，最终 edge health 通过。
- 本机 `rolling-upgrade.sh api-gateway rollback`：回滚镜像后 2 副本健康。

## Non-goals

- 不删除合法保留的财务流水和审计事件。
- 不在本轮伪造 7 天稳定性结果。
- 不做跨区域多活。
