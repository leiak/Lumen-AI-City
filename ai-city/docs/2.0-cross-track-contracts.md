## 1. NPC 全局 ID 格式

- 格式：`npc_<city>_<slug>`
- 示例：`npc_a_wang_boss`、`npc_b_grace_healer`
- 主轨道：跨城联邦
- 从轨道：所有使用 NPC ID 的服务

## 2. agent-os dispatcher.say 返回结构

```python
@dataclass
class DispatcherSayResult:
    npc_id: str          # npc_<city>_<slug>
    text: str            # LLM 生成的台词
    ts_ms: int           # 时间戳
    trace_id: str        # 链路追踪 ID
```

## 3. Milvus collection 命名

- 格式：`mem_<city>_<npc_slug>`
- 主轨道：记忆系统
- 从轨道：跨城联邦（只读访问）

## 4. Saga 事件 schema

```go
type SagaEvent struct {
    SagaID    string            `json:"saga_id"`
    NPCID     string            `json:"npc_id"`     // npc_<city>_<slug>
    PlayerID  string            `json:"player_id"`
    Action    string            `json:"action"`     // say/move/interact
    Payload   map[string]any    `json:"payload"`
    Timestamp int64             `json:"ts_ms"`
}
```

## 5. LLM prompt 模板字段

```python
{
    "system_prompt": str,       # NPC 人设（来自 npc_templates）
```
