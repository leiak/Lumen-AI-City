# 2.0 版本边界与路线（ADR-0007）

> **Status:** Accepted（2.0 阶段 1 已 GA）
> **Reference:** `docs/superpowers/specs/2026-10-03-2.0-stage1-mvp-design.md`

## 目标

在 1.0 闭环基础上，**桶 1 必做 4 项**（LLM-NPC + 记忆 + Saga + 跨城联邦）+ **桶 2 P1**（5 NPC 全开 + 表情），让 AI 公民从 BT 脚本升级为真正 LLM 驱动的 NPC。

## 范围

### 桶 1 必做 4 项

| 轨道 | 内容 | 验收 |
|---|---|---|
| LLM 接入 | Claude Sonnet 4.6 + 5 NPC prompt + chat_turn=6 | acceptance_2_0 step 2 |
| 记忆系统 | Milvus + bge-large-zh + PG fallback + 离线评估 | acceptance_2_0 step 3 (Recall@5 ≥ 70%) |
| Saga 引擎 | Kafka + 补偿事务 + welcome_3npc | acceptance_2_0 step 4 |
| 跨城联邦 | mTLS + 路由表 + 跨城 gRPC + 7 天稳定 | acceptance_2_0 step 5 |

### 桶 2 P1（5 NPC + 表情）

| 内容 | 验收 |
|---|---|
| 5 NPC 全 enabled | wang_boss + grace_healer + snack_owner + book_keeper + dance_leader |
| avatar_url 字段 | web WorldMap 渲染 |
| emoji fallback | 无头像时显示 emoji |

## 容器清单（8 → 13）

继承 1.0（8）+ a2a-gateway 1.0 冻结：
- 已有：postgres × 2、redis × 2、world-engine × 2、api-gateway × 2、ws-gateway × 2、web × 2、agent-os × 2、a2a-gateway
- 新增：memory-service、saga-orchestrator、saga-worker、Milvus、Kafka

## 风险

| 风险 | 缓解 |
|---|---|
| Docker 镜像拉取受限（CN 网络） | 优先 daocloud 镜像；不阻塞代码提交 |
| Milvus 不可达 | PG fallback (recall_from_pg) |
| Saga 步骤超时 | R_007 错误码 + 重试 |
| 跨城 mTLS 证书过期 | renew-certs.sh（到期前 7 天） |
| LLM 月成本超支 | CostTracker + over_budget() 阈值 $100 |
