## 目标

在 1.0 闭环基础上，**桶 1 必做 4 项**（LLM-NPC + 记忆 + Saga + 跨城联邦）+ **桶 2 P1**（5 NPC 全开 + 表情），让 AI 公民从 BT 脚本升级为真正 LLM 驱动的 NPC。阶段 2 在阶段 1 基础上，引入 **LLM 真流式输出 + 8 类 emotion 标签**，让 NPC 对话从"等 30s 一句话"变成"句子级节拍推流 + 表情动画"。

## 错误码（阶段 2 新增 R_011~R_015）

| 码 | 含义 | 触发 |
|---|---|---|
| R_011 | LLM_STREAM_FAIL | LiteLLM 流式连接异常 |
| R_012 | LLM_STREAM_TIMEOUT | 单句 8s 超时 |
| R_013 | EMOTION_PARSE_FAIL | emotion 标签解析失败（降级 neutral） |
| R_014 | REDIS_PUB_FAIL | Redis pub 失败（buffer 重试） |
| R_015 | SESSION_NOT_FOUND | session_id 无效或已过期（60min TTL） |

## 风险（spec §6）

| 风险 | 缓解 |
|---|---|
| LLM 流式延迟 > 句子节拍推送目标（<1s） | 单句超时 8s + 截断降级；observability 监控 p95 |
| emotion 标签 LLM 不稳定（生成失败率高） | validator 降级 neutral + 离线评估集 200 条调优 |
| Redis pub/sub 消息丢失 | 短时（<100ms）丢失可接受；长时走 session buffer 重连补帧 |
| 5 NPC prompt 调优工程量大 | prompt 模板集中文件 + 离线评估集 + 单 NPC LLM 调优循环 |
| web 端 typewriter 体验差（句子突然出现） | NPCDialog CSS transition 200ms fade-in 减弱视觉冲击 |
| LLM 月成本超支 | CostTracker 已有（stage1），单回合多 30% token 计入预算 |
| Docker 镜像拉取受限（CN 网络） | 优先 daocloud 镜像；不阻塞代码提交 |
| Milvus 不可达 | PG fallback (recall_from_pg) |
| Saga 步骤超时 | R_007 错误码 + 重试 |
| 跨城 mTLS 证书过期 | renew-certs.sh（到期前 7 天） |

## 显式不做（spec §7 YAGNI — 阶段 2 推迟）

> 这些会反复被问，每次都用这一节回。

- ❌ **BT 编辑器 v2**（独立 sub-spec B，阶段 3 启动）— 当前 BT 是代码 + cpp.yaml，1.0/2.0 不需要给非工程师的可视化
- ❌ **Saga DSL 可视化**（独立 sub-spec C，阶段 3 启动）— 当前 Saga 是 YAML 数据 + saga-orchestrator 运行时，DSL 是创作者工具
- ❌ **跨城 NPC 流式转发**（阶段 3 延伸，a2a-gateway 已订阅 `aicity:npc:say_stream`）— 阶段 2 仅同城内可见，跨城留待阶段 3
- ❌ **emotion 历史持久化到 memory**（暂仅 UI 临时态）— 阶段 2 emotion 仅渲染一次，无长期存储
- ❌ **流式期间玩家中途打断**（"请等等" 类行为）— 当前阶段不做 stream cancel
- ❌ **NPC 表情 SVG 资源**（先用 emoji fallback，阶段 3 再做）— 阶段 2 只用 8 个 emoji，不做 SVG 动画
- ❌ **多语言 emotion 维度**（仅中文 8 类）— 英文/日文 emotion 留待全球化
- ❌ **emotion 标签的 OCEAN personality 派生**（阶段 3 探索）— 当前 prompt 不引用 OCEAN 5 维度

**C.2 — bt-editor-api** (`apps/bt-editor-api/`)：FastAPI 4 端点 `GET /api/v1/bt/{npc_id}` / `GET /api/v1/bt/{npc_id}/{tree_name}` / `POST /api/v1/bt/{npc_id}/{tree_name}` / `POST /api/v1/bt/{npc_id}/{tree_name}/simulate`；PG `bt_tree` 表 + UNIQUE(npc_id, name) + `bt_tree_bump_version` trigger；body 256KB 上限 + path validation + tick_limit clamp；31 tests。

**C.3 — admin-portal UI** (`apps/admin-portal/src/app/bt-editor/`)：Server shell + React 19 client (BtEditorClient.tsx) + React Flow 可视化（dagre 自动布局）+ Monaco JSON 编辑 + dropdown 选 NPC + R_019/R_020/R_021 错误 toast + version 递增显示；50 vitest unit tests + 1 Playwright E2E。

**C.4 — admin auth** (`apps/admin-portal/src/lib/auth.ts` + `middleware.ts` + `app/login/` + `app/api/auth/`)：
- PG migration `pg-schema-2.0-bt-auth.sql`：`ALTER TABLE player ADD COLUMN IF NOT EXISTS role TEXT NOT NULL DEFAULT 'player'` + 部分索引；mount slot 05。
- Seed `db/seed/seed-admin.sql`：bcrypt(crypt('adminpass', gen_salt('bf'))) + role='admin'；ON CONFLICT 更新密码 + role；mount slot 06。
- `auth.ts`：手写 HS256 JWT（`node:crypto` 唯一依赖 — 无第三方 auth 库）；alg pinning 拒 alg=none + timing-safe HMAC verify + 30s clock skew + role 白名单 (`player` / `admin`)。
- `middleware.ts`：Edge runtime 守卫 `/bt-editor/:path*` + `/api/bt/:path*`；无 cookie → API 401 JSON `{detail:{code:'R_401'}}` / UI 303 → `/login?next=…`。
- `/login` 页 + `/api/auth/login` 路由（JSON + form 双模）+ `/api/auth/logout`；默认 admin/adminpass，env `ADMIN_USERNAME` / `ADMIN_PASSWORD` 覆盖；JWT 复用 `JWT_SECRET=dev-secret-change-me`（与 api-gateway/ws-gateway 一致）。
- `/bt-editor` server component 在 cookie 通过后再次 `decodeToken + isAdmin` 二次校验，防止 JWT 伪造（player cookie 也被拒，渲染友好 403）。
- 主页 `/` 头部 nav：登录态显示 username + 退出按钮，未登录显示「管理员登录」链接。
- 14 vitest unit tests + acceptance_bt_editor.py 7 步 E2E。
