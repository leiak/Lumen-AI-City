# 4.0 M4 Stability Operations Runbook

> **Scope:** M4 D3 的 7 天稳定性窗口。  
> **Do not reset the window unless a P0/P1 failure occurred.**

## Daily operations

```bash
cd ai-city

# 1. Confirm every core service is healthy.
docker compose ps

# 2. Confirm the monitor is alive and has an up-to-date state file.
docker compose --profile stability ps stability-monitor
docker logs aitown-stability-monitor-1 --tail 50

# 3. Refresh the human-readable evidence report.
python scripts/stability-report.py

# 4. Refresh migration / Kafka / backup integrity evidence.
python scripts/stability-integrity.py --once
```

The monitor writes one JSON line every 30 seconds to `artifacts/stability/m4-7d.jsonl` and rewrites `artifacts/stability/m4-7d-state.json`. The report generator summarizes the full window, the last 24 hours, recent failures, and the daily Docker snapshot.

## Acceptance command

Run after seven continuous days:

```bash
python scripts/stability-report.py --strict
```

The command returns `0` only when the window is complete and all M4 D3 budgets pass:

- availability >= 99.9%
- 5xx/error rate <= 0.1%
- P95 <= 2s

## Failure handling

1. Preserve the evidence files; never edit or delete them.
2. Capture `docker compose ps`, `docker compose logs --tail=200`, and the most recent failure rows from `m4-7d-report.md`.
3. Mitigate the incident with the relevant service runbook or rollback procedure.
4. If the incident is P0/P1, archive the current evidence and restart the seven-day window after the fix is deployed.

## Window integrity

- On a database that was initialized by Compose bootstrap SQL, baseline the versioned migration ledger once:

```bash
python scripts/baseline-migrations.py
```

- For production acceptance, run integrity with backups required:

```bash
python scripts/stability-integrity.py --once --require-backup
```

- Keep `artifacts/stability/` out of Git.
- Store one report per day outside the repository before resetting a failed window.
- M4 D3 is not complete until `--strict` returns success for one unbroken window.
