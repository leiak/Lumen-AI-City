# 4.0 M3 Plan — Editor v2 + Production Hardening

> **Status:** In progress（2026-10-13）
> **Parent:** [4.0-ROADMAP.md](4.0-ROADMAP.md)
> **Goal:** 把 M2 的 Agent 模板闭环升级为可运营的编辑器链路，并启动生产基础设施硬化。

## Scope

### P0 — M2 productionization

| # | 任务 | 验收 |
|---|---|---|
| P0.1 | 重建并部署 a2a-gateway / web ✅ | 容器使用最新 M2 代码 |
| P0.2 | Agent 模板端到端冒烟 ✅ | 授权 → 创建 → 查询 → 提交 → 沙箱 → 审批 |
| P0.3 | 运营审批 UI ✅ | 运营可无需 curl 审核草稿 |

### Track C — Creator editor chain

| # | 任务 | 验收 |
|---|---|---|
| C1 | Agent 草稿接入 BT Editor ✅ backend | 草稿可加载、保存版本、BT 投影；编辑 UI 待接 |
| C2 | BT 编辑前校验 ✅ | 深度、引用、节点数、环路在保存前拦截 |
| C3 | 编辑器试运行 ✅ | 使用草稿数据，不写运行时状态 |
| C4 | Saga DSL 可视化编辑 ✅ | 图谱可拖拽连线/删除/编辑属性，结构校验通过后才可导出 YAML |
| C5 | 模板版本与回滚 ✅ | 发布前有版本记录和可回滚快照 |

### Track D — Production infrastructure

| # | 任务 | 验收 |
|---|---|---|
| D1 | Redis ACL / namespace 隔离 | 服务账号最小权限 |
| D2 | Redis 生产配置审查 | 密码、持久化、内存上限、告警明确 |
| D3 | Kafka 主题与消费组巡检 | 关键经济事件不丢、可重放 |

### C2 editor round-trip

- Result: **PASS**（Go 单元测试 + live smoke）。
- Contract:
  - `POST /v1/agent/actions/npc-templates/{id}/editor/validate`：只校验，不落库。
  - `PUT /v1/agent/actions/npc-templates/{id}/editor`：支持 `talk_tree` 或 `bt_editor_tree`，同一请求只允许一种。
- Guards:
  - BT projection 回写先 decode 为 canonical dialogue tree。
  - 再复用 M2 draft 校验：initial/option 引用、唯一 option、节点上限、深度上限、环路。
  - Owner 与 Draft/Rejected 状态仍然强制。
- Evidence:
  - `agent_id`: `c2-smoke-agent-135511`
  - `template_id`: `4`
  - validate: `valid=true`, `source=bt_editor_tree`, `nodes=2`, `depth=2`
  - save: `version=2`, `root.say=edited from bt`

### C3 editor dry-run

- Contract: `POST /v1/agent/actions/npc-templates/{id}/editor/run`
- Modes:
  - `{agent_id, choices}`：使用当前持久化草稿。
  - `{agent_id, talk_tree|bt_editor_tree, choices}`：试运行未保存 payload。
- Guarantees:
  - 不写 `simulation_trace`。
  - 不写 runtime NPC / world state。
  - 运行前复用 C2 校验。
- Evidence:
  - `agent_id`: `c3-smoke-agent-140011`
  - `template_id`: `5`
  - draft run: `sandbox=true`, `status=completed`, `first_say=hello`
  - unsaved BT run: `source=bt_editor_tree`, `status=completed`, `first_say=unsaved run`

### C5 versioning

- Contract:
  - `GET .../editor/revisions?agent_id=...`
  - `POST .../editor/rollback`
- Rules:
  - Draft / Rejected 才能回滚。
  - 回滚写入新的递增 version，不覆盖 revision 历史。
  - Operator 审批链路仍以模板最终状态为准。
- Evidence:
  - `agent_id`: `c3-smoke-agent-140011`
  - `template_id`: `5`
  - save v2: `root.say=version two`
  - revisions: `count=2`, `newest=2`
  - rollback v1: `new_version=3`, `root.say=hello`

- 不做完整 3D 编辑器
