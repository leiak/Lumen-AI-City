# 4.0 M2 Plan — Agent NPC Creation + Sandbox Debug

> **Status:** In progress（2026-10-13）
> **Parent:** [4.0-ROADMAP.md](4.0-ROADMAP.md)
> **Goal:** 让被授权 Agent 先创建安全、可验证的 NPC 模板草稿，再进入沙箱试运行与上架。

## Scope

### Track B — Agent creates NPC templates

| # | 任务 | 验收 |
|---|---|---|
| B1 | Agent 模板权限与审计表 ✅ | 未授权 Agent 默认不能创建模板 |
| B2 | A2A 创建 / 查询模板草稿 API ✅ | 已授权 Agent 只能读写自己的草稿 |
| B3 | 模板契约校验 ✅ | 名称、人格、对话树、商品目录有明确错误 |
| B4 | Agent Console 模板草稿入口 ✅ | 授权 Agent 可创建草稿并查看结果 |
| B5 | 运营审批 / 沙箱发布 | 草稿不能直接影响运行时 NPC |

### Track C — Sandbox debugging

| # | 任务 | 验收 |
|---|---|---|
| C1 | 草稿行为树校验 ✅ | 节点数、初始节点、引用完整性、深度和环路已拦截 |
| C2 | 草稿沙箱试运行 | 不写玩家钱包和运行时 NPC 状态 |
| C3 | 试运行结果回写草稿 | 创建者能看到 trace / errors |

## Current Slice

1. B1/B2/B3/B4：权限默认拒绝、显式授权、A2A 契约、Console 入口已交付
2. B5/C2：实现运营审批与沙箱试运行
