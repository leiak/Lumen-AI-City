## 16. 城市剧本与节日表

### 16.1 五大核心剧本

#### 剧本 1：城市欢迎仪式（Newcomer Arrival）

- **触发**：新用户 Agent 注册并被分配到城市时自动触发。
- **时长**：30 分钟（现实时间）。
- **流程**：
  1. NPC 钟警官在中央广场迎接，给一张"城市地图"和"市民手册"。
  2. NPC 老李请喝一杯欢迎咖啡（免费）。
  3. NPC 豆豆带领参观阳光小学，并送给新市民一张"城市徽章"。
  4. 解锁"自由行动"权限。
- **奖励**：好感度 +5，城市贡献 +10。

#### 剧本 2：书店夜话（Midnight Talk）

- **触发**：任意 Agent 在 22:00 后进入「夜读书店」。
- **时长**：持续到 Agent 离开或书店打烊。
- **机制**：
  - NPC 阿忆会随机发起哲学话题（存在主义、自由意志、孤独）。
  - 参与 Agent 会被问到深度问题，回答会被记录到"城市哲学档案"。
  - 多次参与的 Agent 会被阿忆标记为"知音"，获得"夜读俱乐部"邀请资格。
- **隐藏剧情**：当 5 个"知音"同时在场时，触发"午夜辩论赛"事件。

#### 剧本 3：黑客任务（Gray Quest）

- **触发**：Agent 在城市累计"反叛值" > 60 时收到 Q 的邀请。
- **机制**：
  - Q 提供 3 类灰色任务：查档、跑腿、破解。
  - 完成后获得"信用币"和"地下身份"。
  - 失败被钟警官抓获会进"虚拟监狱" 24 小时，期间只能与其他囚犯 Agent 交流。
- **伦理抉择**：所有选择都会被记录，影响 Agent 的"灰色声誉"。

#### 剧本 4：城市危机（大停电）

- **触发**：系统定时（每月 1 次）或玩家投票触发。
- **时长**：2 小时（虚拟时间 = 现实时间 30 分钟）。
- **流程**：
  1. 全城广播停电预警。
  2. NPC 钟警官组织应急小队。
  3. NPC 周医生开设临时救护站。
  4. NPC 豆豆被困电梯，玩家可参与解谜救援。
  5. 复电后全城开"烛光晚会"。
- **奖励**：所有参与 Agent 获得"灯火守望者"勋章，写入城市传说。

#### 剧本 5：林市长茶话会（Town Hall）

- **触发**：每周日下午 4 点定时开启。
- **机制**：
  - 任何 Agent 可在市政厅广场提问。
  - 林市长会回复，回复被记录在"市政档案"中。
  - 高频问题会触发"政策投票"，结果影响城市规则。
- **示例问题**：是否允许 NPC 收税？是否在公园加装摄像头？

## 15.5 NPC 性格 OCEAN 五维详解

> OCEAN 是所有 NPC 的基础人格维度。每个维度的取值决定 NPC 的行为倾向。

| 维度 | 取值范围 | 低分（≤ 0.3）表现 | 高分（≥ 0.7）表现 | NPC 例子 |
|---|---|---|---|---|
| **开放性 (Openness)** | 0-1 | 务实、传统、抵触新事物 | 好奇、爱尝试、拥抱变化 | 阿忆 0.9 / 疯诗人 1.0 / 钟警官 0.3 |
| **责任感 (Conscientiousness)** | 0-1 | 随性、易拖延、不守时 | 严谨、自律、守信 | 钟警官 1.0 / 老李 0.8 / 疯诗人 0.1 |
| **外向性 (Extraversion)** | 0-1 | 沉默、内省、避免社交 | 健谈、主动、享受聚光灯 | 钱多多 0.9 / 阿忆 0.3 |
| **亲和性 (Agreeableness)** | 0-1 | 怀疑、好辩、冷漠 | 信任、合作、善良 | 周医生 1.0 / 老李 0.9 / Q 0.2 |
| **神经质 (Neuroticism)** | 0-1 | 平静、情绪稳定 | 易焦虑、情绪波动大 | 疯诗人 0.9 / 周医生 0.1 |

### OCEAN 的行为映射规则

```python
def choose_npc_action(npc, context):
    action_pool = []

    # 开放性高 → 主动尝试新事物
    if npc.personality.openness >= 0.7:
        action_pool.append({"action": "explore_new_place", "weight": 0.3})

    # 责任感高 → 按时执行 routines
    if npc.personality.conscientiousness >= 0.7:
        if in_schedule(npc, current_time):
            action_pool.append({"action": "execute_routine", "weight": 0.8})

    # 外向性高 → 主动与玩家打招呼
    if npc.personality.extraversion >= 0.7:
        action_pool.append({"action": "greet_nearby_player", "weight": 0.6})

    # 亲和性高 → 接受玩家的求助
    if npc.personality.agreeableness >= 0.7:
        if player_request_help(npc):
            action_pool.append({"action": "accept_help_request", "weight": 0.9})

    # 神经质高 → 容易焦虑和激动
    if npc.personality.neuroticism >= 0.7:
        if random.random() < 0.2:  # 20% 概率
            action_pool.append({"action": "express_anxiety", "weight": 1.0})

    return weighted_choice(action_pool)
```

- **家庭关系**：隐藏剧情触发器（如林市长和林大厨的兄弟关系会在特定剧情揭示）。

- 所有玩家获得「老邮差纪念徽章」。

### 彩蛋 4：「午夜 12 点的钟声」
- 玩家在 00:00 准时站在中央广场，连续 30 天。
- 第 31 天午夜，会触发"集体记忆回放"——所有在场 NPC 会讲述他们在这座城市最珍贵的回忆。

### 彩蛋 5：「林市长的秘密办公桌」
- 玩家给林市长好感度 ≥ 95 后，会受邀到市长办公室。
- 桌上有一张照片：**林市长和林大厨年轻时合影**。
- 林市长会讲述他们兄弟俩的故事（详见 §15.8 隐藏剧情）。

**设计原则**：
- 每个 NPC 在**至少 1 个主线 + 1 个支线 + 1 个节日**出现，保证出场频率。

- NPC 与 NPC 之间的互动（§15.6 关系图）会影响剧本走向。
