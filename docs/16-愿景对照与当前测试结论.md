# 愿景对照与当前测试结论

> 更新时间：2026-10-10  
> 测试基准：`/city` 实机预览、A2A Gateway 实机 Agent 操作、A2A/API Gateway 单元测试、Web 构建。

## 1. 一句话结论

**原始方向一致，但当前还不是完整的“全 Agent 城市”。当前形态更接近：**

1. **AI 城市垂直原型**：地图、NPC、玩家/Agent 位置、脚本化对话已经能看。
2. **Agent 协议骨架**：第三方 Agent 注册、发现、移动、A2A 消息、NPC 行为树读取/执行已经跑通。
3. **经济系统先行版**：钱包、商品购买、创作者市场、跨城金币等后端能力已经闭环，但还没有充分融入城市玩法。

这不是失败，而是当前里程碑的实际形状；但必须避免把“后端 GA”误读为“城市体验 GA”。

| 原始愿景层 | 当前成熟度 | 判断 |
|---|:---:|---|

| Agent ↔ Agent 通信 | 🟡 协议可用，体验基础 | 消息收发和 Agent Console 有基础入口；群聊、广播、地理/关系/情感标签仍需完善。 |

## 4. 本轮暴露的主要缺口

| 优先级 | 缺口 | 影响 | 处理方向 |
|---|---|---|---|
| P0 | 游客地图读取曾命中鉴权接口，出现 `API 401` | 游客预览不稳定，地图首载体验差。 | 已把 `GET /v1/tiles` 调整为公开只读路由，并已重建 `api-gateway` 验证生效。 |
| P0 | 登录链路不稳定 | 已登录玩家、HP/钱包、个人能力无法稳定进入完整体验。 | 修复 demo 登录、JWT、token 注入和 `/v1/players/me` 链路。 |
| P0 | 城市页状态仍简单 | 用户只能看到 tile、NPC、聊天和 Agent Console，缺少身份、任务、财产、事件反馈。 | 将经济、任务、记忆和 Agent 目标接入 HUD。 |
| P1 | Agent 能力缺少统一说明 | 第三方 Agent 不知道边界、可做什么、不能做什么。 | 已有 `ai-city/docs/agent-integration-guide.md`，需持续更新到 7 个 NPC 与完整动作集。 |
| P1 | 经济/市场还有体验缺口 | 购买反馈、发布和收益查询已能演示，但模板草稿、下架和提现仍缺失。 | 继续完善创作者经营闭环。 |
| P1 | NPC 行为缺乏连续性 | NPC 主要被动响应或脚本移动，没有长期目标。 | 给 NPC 增加日程、目标、关系、记忆注入和行动日志。 |
| P2 | 数百 NPC / 三层 LOD / 大规模同步 | 距离原始城市愿景还远。 | 先做 30–50 个 NPC 的街区切片，再扩展 LOD 和分片。 |

## 5. 下一步顺序建议

1. **稳定人类玩家闭环**：游客地图、登录、token 注入、玩家 HUD、移动反馈。当前基础闭环已通。
2. **城市内接入经济**：钱包余额、NPC 商品、购买、背包、转账、市场浏览/购买、发布、收益面板和交易历史已通；继续补齐模板草稿、下架和提现。
3. **完善 Agent 边界与能力面板**：Agent 移动、对话、查看行为树、经济能力、审计日志。
4. **NPC 生活感**：日程、目标、关系、记忆摘要、自动播报开关。
5. **回到原始愿景扩容**：更多 NPC、街区级 LOD、城市事件、关系图谱和跨城体验。
