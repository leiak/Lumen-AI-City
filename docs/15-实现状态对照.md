## 15.2 经济服务能力

| 能力 | 入口 | 结果 |
|---|---|---|
| 查询钱包 | `GET /api/v1/wallet/{user_id}` | 返回 gold/token 余额与时间戳；不存在返回 `R_018` |
| 钱包转账 | `POST /api/v1/wallet/transfer` | 事务扣款/入账，写两条流水，Redis 幂等 |
| 查询 NPC 商品 | `GET /api/v1/products/{npc_id}` | 返回启用商品 |
| NPC 商品购买 | `POST /api/v1/wallet/purchase` | 事务内锁商品与钱包，扣款、扣库存、写 `npc_purchase` 流水；Redis 幂等 |

错误码基线：

| HTTP | code | 场景 |
|---|---|---|
| 404 | `R_018` | 钱包不存在 |
| 402 | `R_022` | 余额不足 |
| 400 | `R_023` | 自己转给自己 |
| 409 | `R_024` | 商品缺货 |
| 404 | `R_025` | 商品不存在或已禁用 |
