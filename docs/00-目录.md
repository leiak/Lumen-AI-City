# AI城邦 - "全Agent城市" 设计文档目录

> **目标**：打造一座基于真实或半虚构地图的 2.5D/3D AI城邦，支持数万含人类数字分身及 openClaw/workbuddy 等第三方联邦协议接入的 Agent 公民，在拥有昼夜与季节演进的持续运行世界中，实现玩家、Agent、环境与现实世界的高自由度自治交互。
>
> **核心**：**地图 + 协议 + Agent 三位一体**。
> **哲学**：**先求"不崩"再求"好玩"**，工程化的最小规则从第一天就落地。

## 五大部分速览

### 第一部分（§0–§14）：愿景与架构骨架
- **战略层**：核心原则（P0-P2 需求）、关键场景、高阶架构。
- **战术层**：地图 LOD、技术选型、Agent 协议、关键挑战与对策。

### 第二部分（§15–§24）：深度实现细节
- 把"骨架"展开为"血肉"：NPC 人设、剧本、数据 Schema、API、Agent OS、A2A 协议、MVP 任务、ADR、商业模式。

### 第三部分（§25–§32）：架构优化与 MVP 重塑
- 评审五大问题 → 重构策略：
  - Neo4j 异步化（写读分离）
  - 记忆三层防御（防幻觉级联）
  - A2A Schema + Safe-LLM（防注入）
  - Saga 分布式补偿事务
  - MVP 砍到 6-8 周

### 第四部分（§33–§41）：第二轮工程加固
- 二次评审盲区 → 深度加固：
  - 多层 Token 配额 + LLM Provider 多路复用
  - 跨 Tile 分布式锁 + Kafka 异步
  - AI 警察彻底删除（伦理红线）
  - 优雅降级矩阵 + 灾备切换
  - SLI/SLO + 监控大盘 + 告警
  - 24h 压测 + 故障注入剧本

### 第五部分（§42–§49）：低成本工程化优化五条
- "最小规则"原则（5 天工时，60-98% Token 节省）：
  1. **对话回合计数器**（`chat_turns`，6 回合强制收尾）
  2. **LOD 主角色 / 背景板**（仅 L0 走 LLM，节省 96%）
  3. **记忆分值与时限**（`created_at` + `importance` 1-5）
  4. **单行 JSON 日志**（决策可复现）
  5. **关键词过滤 + 频率限制**（3 秒最小动作间隔）
